# UX/UI Gym

Prototipo visual en React Native para un sistema de gestion de gimnasio,
basado funcionalmente en el proyecto de referencia `/home/envy/gym`.

Este proyecto se enfoca solo en experiencia de usuario, interfaz, navegacion,
estados visuales y datos mock. No debe conectarse todavia a backend real.

## Documentacion

- `docs/producto.md`: alcance del producto y modulos principales.
- `docs/navegacion-y-roles.md`: estructura de pantallas y visibilidad por rol.
- `docs/flujos-ux.md`: recorridos principales que debe cubrir el prototipo.
- `docs/datos-mock.md`: entidades y escenarios mock necesarios para disenar.

## Fuera de alcance por ahora

- Integracion con API real.
- Persistencia real.
- Autenticacion real.
- Deploy.
